# Document Archiving

A unified document archiving solution based on and bringing together some of my earlier work:

- [Doc-Archiving](https://github.com/theretrobristolian/Scripts/tree/main/Doc-Archiving)
- [Align-TIF](https://github.com/theretrobristolian/Scripts/tree/main/Align-TIF)
- [Deskew](https://github.com/theretrobristolian/Scripts/tree/main/Deskew)
- [TIF-Converter](https://github.com/theretrobristolian/Scripts/tree/main/TIF-Converter)

The aim of this project is to consolidate the separate document processing, image alignment, deskewing and TIFF conversion workflows into a single document archiving solution.

The solution uses [IrfanView](https://www.irfanview.com/) alongside other open-source software and supporting tools.
